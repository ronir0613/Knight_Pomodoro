# Privacy Policy — Knight Pomodoro

**Last updated:** September 2026

## What data is collected

Knight Pomodoro stores the following data locally on your device:

- Timer state (current phase, remaining time)
- User settings (durations, blocklist, preferences)
- Daily focus statistics (focused time, browsing time, completed sessions)

## Where data is stored

All data is stored exclusively in your browser's local storage (`chrome.storage.local`). No data is transmitted to any external server.

## Data sharing

Knight Pomodoro does not sell, share, or transmit any user data to third parties. There are no analytics, telemetry, or crash reporting services.

## Data deletion

You can delete all stored data at any time via Settings → Data → "Clear all data", or by uninstalling the extension.
